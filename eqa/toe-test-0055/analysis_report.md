- branch / positivity / guard meaning becomes harder to inspect

## Missing-Link Result

The experiment exposed the shape of the IR TOE actually wants:

- uniform enough for search
- first-class multiplication / ratio / sign handling
- explicit guard-carrying metadata
- preserved readability for beta, omega, and EFT inequalities
- likely two-level architecture:
  - frontend native analytical contracts
  - backend normalized search representation

AEFSO fits the backend half better than the frontend half.
