Flamehaven Verification Ledger API v1

Static read-only JSON API — served via GitHub Pages — no backend.

Endpoints

GET api/v1/runs.json
Index of all verification runs across EQA / BAV / BSC lanes (id, verdict, brief, detail_url)
GET api/v1/runs/{id}.json
Per-run detail — summary, key_metrics, findings, evidence links. Example: runs/bav-exp-034.json
GET api/v1/metrics/bav.json
Aggregated BAV pipeline metrics table (SR9, DI2, p_e2e, balanced_accuracy per experiment)
GET api/v1/schema.json
Vocabulary — lane descriptions, 11 verdict codes, 6 metric definitions
All files are pre-generated from each experiment’s manifest.json — no live computation. View the full ledger at flamehaven01.github.io/Flamehaven-Verification-Ledger or the source on GitHub.
